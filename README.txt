Makuru Crops Company — static website
=====================================

Upload this entire folder to any hosting platform (cPanel, Netlify, GitHub Pages, Hostinger, etc.).

Required structure (do not rename folders):
  index.html
  css/styles.css
  js/main.js
  images/   (all photos, logo, favicon)

How to go live:
1. Unzip this file.
2. Upload ALL contents so that index.html is in the website root (public_html or similar).
3. Visit your domain. The home page is index.html.
